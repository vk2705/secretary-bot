<objective>
Expand the tracer's single proven path across all seven scheduled behaviours, so every scheduler-driven message in this milestone can be triggered on demand.

The architecture was settled in plan 01-01: each job body becomes a module-level `_run_*` function and `schedule_user_*` keeps only a thin `run_daily` wrapper. This plan applies that shape five more times and adds the dispatch registry. The one genuinely new design element is honest reporting: several job bodies short-circuit on guards — quiet hours, mute, not-Sunday, not-idle-long-enough, nothing-due — and a debug fire that hits one of those must say so rather than appear broken.

Purpose: close DEBUG-01 completely. ROADMAP.md states no other phase may touch this code concurrently this milestone, so the extraction lands here in full.
Output: `/debug fire` covering all seven targets, with the scheduled paths provably unchanged.
</objective>
